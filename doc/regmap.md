## 9 TEST_CTRL_0

Test control. 15:11 are this chip's decimator stimulus. Enable and trigger are separate on purpose: the decimator holds about 32 output samples of history, so enable first, let the output settle on the idle pattern, then trigger. 10 is the flag synchronizer, 9 belongs to the analog top, 8 is PAD_Q, 7:6 the bias test mux, 5:0 the core test mux. The core mux rules, one integrator at a time and neutral between two nodes, are in models/regmap.py.

| Bits | Field | Reset | Rule | Description |
|---|---|---|---|---|
| 15 | STIM_OPT | 0x0 |  | Repeat flag for the event patterns, variant select for the steady one (only on cmos5l) |
| 14:13 | STIM_PAT | 0x0 |  | Pattern. OPT=0 once, OPT=1 repeat every 64 output samples (steady, OPT=1 is PRBS23) STEP_P = 0, IMPULSE = 1, STEADY = 2, STEP_N = 3 (only on cmos5l) |
| 12 | STIM_TRIG | 0x0 |  | A rising edge arms, the stimulus fires at the next valid_strobe (only on cmos5l) |
| 11 | STIM_EN | 0x0 |  | Stimulus onto the decimator instead of data_in (only on cmos5l) |
